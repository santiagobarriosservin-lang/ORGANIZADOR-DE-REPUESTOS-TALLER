# Registro de repuestos del taller electromecánico

Programa en Python para registrar los repuestos de un taller: cargarlos, buscarlos, actualizar su cantidad, entregarlos y darlos de baja.

## Autor
Santiago Barrios Servín, 4to año.

## Cómo ejecutarlo
1. Tener Python instalado.
2. Abrir el archivo en Visual Studio Code.
3. Ejecutarlo con el botón Run (el triangulito).

## Qué se puede hacer
1. Agregar un repuesto (no permite códigos repetidos).
2. Buscar un repuesto por código.
3. Actualizar la cantidad.
4. Ver la lista completa.
5. Entregar repuestos (solo si hay stock suficiente).
6. Eliminar un repuesto.
7. Salir.

## Aviso
Los datos se borran al cerrar el programa.
Manual de usuario

Abrir el programa: aparece un menú con números. Escribí el número de lo que querés hacer y apretá Enter.
Cargar un repuesto (1): escribí el código, el nombre, la marca, la cantidad y la fecha con barras, por ejemplo 11/11/2026.
Buscar (2): escribí el código del repuesto y te muestra sus datos.
Cambiar la cantidad (3): escribí el código y la cantidad nueva.
Ver todos (4): muestra la lista completa.
Entregar (5): escribí el código y cuántos se llevan. Si no alcanza el stock, el programa avisa.
Eliminar (6): escribí el código del repuesto que querés borrar.
Salir (7): cierra el programa. Ojo: al salir se borran todos los datos.
